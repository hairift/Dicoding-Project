# Machine Learning Dicoding 1.1

Repositori ini digunakan untuk belajar dan menyimpan pengerjaan proyek machine learning dari program Dicoding.

## Isi proyek

Folder `Machine_Learning` berisi submission akhir yang menerapkan dua pendekatan:

- **Clustering** menggunakan K-Means untuk membentuk label `Target`.
- **Klasifikasi** menggunakan Decision Tree, Random Forest, dan hyperparameter tuning.

Notebook dan model yang tersedia dibuat sebagai bahan belajar pribadi. Dataset digunakan untuk latihan analisis data, preprocessing, evaluasi model, dan dokumentasi proses machine learning.

Notebook submission mengikuti struktur template proyek Dicoding, termasuk heading, cell keluaran, proses clustering, interpretasi cluster, dan klasifikasi.

## Catatan

Proyek ini dibuat untuk keperluan pembelajaran. Silakan menyesuaikan nama notebook dan konfigurasi dataset sebelum digunakan untuk submission resmi.
